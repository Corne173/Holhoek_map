BEFORE YOU SET OFF

A little preparation.
A lot of exploring.

This HTML file contains the trails, pins, and map controls. Download it while you have reception, then open it in a browser. No account is needed.

Take it offline

The downloaded HTML works without internet. On a hosted copy, use “Save for offline” on this device before leaving reception. Browser storage can be cleared, so reopen the map in airplane mode before you set off.

Download the single HTML file
Your location

Your phone’s GPS can work without mobile reception. Allow location access when asked. This is most reliable on the secure hosted version; local HTML files are restricted by some phone browsers. Your position stays on your device.

A trail map for now

Satellite imagery and waypoint photos are not included in this edition. The map uses your KMZ routes and coordinates. Distances are approximate lengths of the drawn routes.

Check the map on your phone before your hike. Trail conditions and access can change; this guide does not provide turn-by-turn navigation.
